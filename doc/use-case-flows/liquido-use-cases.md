# LIQUIDO Use Cases

This file shows the use cases from and end user perspective. See readme-tech.md for the more technical detaisl.

## Settings for a poll

The admin can configure the following settings for a poll.

 * Team members can add proposals.
 * Voters can change their vote, as long as the poll is running

Votes in LIQUIDO are always anonymous!
If you need a vote where members can vote for more than one candidate, you already have that. Just simply sort your favorite candidates to the top.
